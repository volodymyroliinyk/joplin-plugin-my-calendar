# Full Featured Event

An example showing almost all available non-recurring properties.

```mycalendar-event
title: Workshop: Advanced Joplin Plugins
start: 2026-08-12 14:00+02:00
end: 2026-08-12 17:30+02:00
color: #9b59b6
location: Virtual Meeting Room 4
description: A deep dive into Joplin's API and plugin development.
Bring a laptop with the development profile already configured.
```

Continuation lines belong to `description`, so multiline descriptions remain readable in the calendar day view.
